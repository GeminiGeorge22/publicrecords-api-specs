# Composio toolkit: publicrecords

- **Name:** publicrecords
- **Description:** Agent tools for public web data: Etsy listings and shop sales, live sports odds from
  Kambi-powered sportsbooks, new job postings from Ashby/Greenhouse/Lever/SmartRecruiters boards,
  US, EU and UK government tenders, grants and awards, city council meetings, company social
  profiles, and forecast calibration.
- **Categories:** Data & Analytics, E-commerce, Sports, Recruiting, Government
- **Auth:** API key. Header `Authorization: Bearer <Apify API token>` (the end user's own token,
  from Apify Console > Settings > API & Integrations).
- **Base URL:** https://api.apify.com/v2
- **Spec:** `publicrecords-openapi.json` (15 actions, one per Actor; each returns result rows)
- **Docs:** https://github.com/GeminiGeorge22/publicrecords-api-specs and https://apify.com/publicrecords
- **Technical contact:** publicrecords@agentmail.to
